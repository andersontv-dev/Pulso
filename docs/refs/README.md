# Referencias visuales

El brief adjuntó tres capturas de dashboards (banca personal, panel financiero
y panel de logística) como guía de **densidad de información y jerarquía
visual**, explícitamente no para copiarlas.

Llegaron como imágenes en la conversación, no como archivos, así que no se
pueden versionar aquí. Lo que se tomó de ellas queda registrado:

- **Fila de KPIs arriba**, con el valor grande y la variación como dato
  secundario junto a él. En las tres referencias es lo primero que se lee.
- **Densidad alta en la tabla**: muchas filas visibles sin scroll, altura de
  fila compacta, alineación numérica a la derecha.
- **Filtros a la altura del encabezado**, no escondidos en un panel lateral.
- **Estado como etiqueta con color de fondo suave**, no como texto coloreado
  suelto.

Lo que se descartó deliberadamente: el gradiente decorativo de fondo, las
tarjetas con sombras pronunciadas y las paletas multicolor. Nada de eso encaja
con la línea gráfica de 30X (ver `docs/brand.md`).
